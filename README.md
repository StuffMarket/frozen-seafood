# Frozen Seafood Cold Storage Directory

Independent supplier research for frozen seafood imports into Durban, South Africa.

**Prepared by Milton Marino — October 2026**

## Open and deploy

- Open `index.html` directly in a web browser.
- Deploy to **Vercel** by importing this GitHub repository and selecting **Framework Preset: Other**. There is no build command or output directory required; the root contains `index.html`.
- For a PDF, open the website and select **Save / Print PDF** (browser destination: Save as PDF).

## Features
- Responsive HTML / CSS / vanilla JavaScript, no backend.
- Supplier directory with Durban and regional filters.
- Click-to-call, editable `mailto:` enquiry template, copy-email and Google Maps search links.
- Official supplier source links; uncertain fields are explicitly flagged.
- Print stylesheet for a shareable report.

## Data quality
Research compiled from GPT Deep Research and Perplexity reports. Published capacity is **not** available space. Do not infer that all listed candidates accept 37+ tonnes of Mozambican frozen seafood. Before contracting, confirm in writing temperature, seafood acceptance, space, date, rates, bonded/customs requirements and handling.

Contacts may change. Email drafts are never sent automatically. Location links open Google Maps search for the listed address and should be checked before any physical visit.
